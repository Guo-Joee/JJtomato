# JJtomato · Electron 玻璃版

## 版本说明

### v0.1.6（当前版本）

- 修复置顶小窗时间不准、运行一段时间后突然卡住的问题
- 主窗口隐藏后关闭 Electron Renderer 后台计时节流
- 计时状态改为只由主窗口发布，小窗不再反向发送默认时间
- 小窗打开或再次显示时立即拉取最新计时状态

### v0.1.4

- 修复左键拖动置顶小窗时窗口尺寸缓慢变大的问题
- 关闭 Windows 原生边缘缩放，避免原生 resize 与拖动 IPC 冲突
- 小窗尺寸继续通过右键菜单调整
- 保留 v0.1.3 的 Pointer Events + Electron IPC 拖动方案

### v0.1.5

- 修复笔记本内屏高 DPI 下拖动小窗会慢慢变大的问题
- 不再混用浏览器 `screenX/screenY` 与 Electron 窗口坐标
- 改用 Electron `screen.getCursorScreenPoint()` 统一处理多显示器坐标
- 兼容笔记本内屏与外接副屏不同缩放比例

### v0.1.3

- 修复置顶小窗无法左键长按拖动的问题
- 改用 Electron IPC + Pointer Events 处理小窗移动
- 保留中心双击返回主页面和右键调整大小

### v0.1.2

- 统一 Windows 应用图标、桌面快捷方式、任务栏和托盘图标为番茄图标
- 新增多尺寸 `assets/icon.ico`（16/20/24/32/48/64/128/256）
- 修复快捷方式和导航栏显示 Electron/Hermes 图标的问题

### v0.1.1

- 修复置顶小窗双击无法返回主窗口
- 小窗中心区域支持双击返回，外围继续支持拖动
- 主窗口恢复流程增加最小化状态处理

### v0.1.0

- 首个 JJtomato Electron 玻璃版
- 专注、短休、长休计时
- 任务列表、本地持久化、托盘、透明度和置顶小窗

Electron + React 重做版本。主题：番茄、Ins 生活方式、半透明磨砂玻璃、柔和动态光影。

## 核心设计

- 大计时圆环独立安全区，控制按钮永不覆盖圆环
- 专注 / 短休 / 长休使用清晰分段控制
- Win11 尝试使用系统 Acrylic 背景材质；Win10 自动降级为 CSS 半透明玻璃
- 动态柔光背景、平滑进度动画、模式切换和设置抽屉动效
- 右上角仅保留最小化与关闭
- 置顶功能统一为底部“置顶小窗”入口
- 设置为 React 玻璃抽屉，不创建额外 Qt 弹窗

## 快捷键

- `Space`：开始 / 暂停
- `R`：重置当前阶段
- 双击置顶小窗：返回主窗口

## 开发

```bash
npm install
npm test
npm run dev
npm run electron
```

## 构建

```bash
npm run dist
```
