# JJtomato · Electron 玻璃版

## 本地开发启动

请在项目目录中启动：

```powershell
cd C:\Users\Administrator\Desktop\JJtomato-main
npm run dev
```

然后打开 <http://127.0.0.1:5173/>。

`npm run dev` 已经在脚本中配置了 `--host 127.0.0.1`，不要再次执行 `npm run dev -- --host 127.0.0.1`，否则部分 npm 版本会把重复的 `127.0.0.1` 误解析成 Vite 项目目录并返回 404。

- 新增本地“陪伴房”模型：邀请码、成员、成员级共享权限和最近 100 条房间事件

### v0.1.21

## 核心设计

- 大计时圆环独立安全区，控制按钮永不覆盖圆环
- 专注 / 短休 / 长休使用清晰分段控制
- Win11 尝试使用系统 Acrylic 背景材质；Win10 自动降级为 CSS 半透明玻璃
- 动态柔光背景、平滑进度动画、模式切换和设置抽屉动效
- 右上角仅保留最小化与关闭
- 置顶功能统一为底部“置顶小窗”入口
- 设置为 React 玻璃抽屉，不创建额外 Qt 弹窗

## 快捷键

- `Space`：开始 / 暂停
- `R`：重置当前阶段
- 双击置顶小窗：返回主窗口
